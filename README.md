# Кото-Балаган (MP-сервер)

Одностраничная игра-клон The Battle Cats с мультиплеером: общий чат (WebSocket),
профили с аватарками, друзья и живой PvP (реальное время).

**Запуск:** `npm install && npm start` (порт — переменная `PORT`, по умолчанию 8080).

Сервит:
- `/` — игра (index.html)
- `/ws` — WebSocket (чат, присутствие, друзья, PvP-релей)
- `/api/chat` — HTTP GET/POST (совместимость)
- `/api/health` — статус
